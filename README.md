## How to use

1. Upload a CSV containing the URLs you want to check OR add a text list of URLs
2. Enter the sitemap/sitemap index URL
3. If you want to check the status code of each URL, untick “Turn off status code checker”
4. Click Submit and you'll get your list of checked URLs, the status code if you unticked the option, and the status (whether it's in the sitemap or not)
